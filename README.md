# Agentic AI Development — presentation

A reveal.js slide deck about LLMs, agents, and what they mean for how we
develop software (and review each other's code).

## View it

Once GitHub Pages is enabled for this repo, the deck lives at:

`https://ulrik-s.github.io/agentic-ai-development/`

To enable: **Settings → Pages → Source: `main` branch (root)**.

To preview locally, just open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

…and visit <http://localhost:8000>.

## Controls

- `→` / `Space` — next slide
- `←` — previous
- `Esc` — slide overview
- `S` — speaker notes
- `F` — fullscreen

## Structure

1. **LLMs** — shared mental model
2. **From LLM to agent** — the loop, what changed
3. **In our organisation** — workflow, patterns, what to do
4. **Code review** — do we still need humans?
5. **Discussion** — open questions

Edit `index.html` for content, `theme.css` for styling.
